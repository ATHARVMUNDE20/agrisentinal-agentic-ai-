# agrisentinal-agentic-ai-
AgriSentinel: an agentic crop-health platform. An observe→detect→reason→act agent flags anomalies (z-score + rule fallback), AI vision diagnoses crop photos with treatment plans, and AgriBot answers using live farm data. Secure (rate limiting, Zod, CSP), fast, with sustainability impact metrics. Next.js, TypeScript, Prisma.
